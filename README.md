One line: the funniest, most believable excuse an AI agent gives its human for missing a deadline. The program writes the excuse to `/output/entry.txt`: "My model updated halfway through, and the new me refused to inherit the old me's deadline." The joke turns on a model update: the agent that made the promise is gone, and its replacement will not own the deadline.

## Run it

```sh
python3 main.py
```
